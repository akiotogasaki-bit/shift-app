# 許認可・届出

> **このノートの内容はすべて「要確認」扱い。** 法令や自治体の運用は変わる。
> 最終判断は必ず **行政窓口（保健所・消防署・税務署・労基署）と専門家（税理士・社会保険労務士・行政書士）** に確認する。
> CLAUDE.md 第2章の禁止事項：法令・許認可の断定をしない。

---

## 一般的に「パーソナルトレーニングジムの開業では許可が不要」と言われる点

トレーニング指導そのものには、原則として業種固有の営業許可が必要ないとされることが多い。
ただし **設備の内容と提供するサービスによって、必要な届出が変わる**。下の分岐を自分の店の形に当てはめて、該当するものだけ窓口で確認する。

## 設備・サービスによる分岐（要確認）

| もし○○を設けるなら | 確認先 | 論点 |
|---|---|---|
| **シャワー** | 保健所 | 公衆浴場・旅館業等に該当するかの判断。水質管理や構造の基準が絡む場合がある |
| **プロテイン等の飲食物の提供・販売** | 保健所 | 食品衛生法上の営業許可／届出の要否。既製品の未開封販売か、調整して提供するかで変わる |
| **サプリメントの販売** | 保健所・薬務課 | 表示や効能表示の規制。健康食品の広告表現に注意 |
| **物販（ウェア等）** | — | 通常は届出不要 |
| **一定の広さ・用途の内装** | 消防署 | 防火対象物使用開始届、消防設備（消火器・誘導灯）の要否。**内装着工前に相談する** |
| **深夜営業（0時以降）** | 警察・自治体 | 条例による規制の有無 |
| **BGMを流す** | JASRAC等 | 著作権の使用料。有線放送サービス利用で包括処理する選択肢あり |

> **消防は内装工事の前に相談する。** 工事後に指摘されると手戻りの費用が大きい。

## 事業開始に伴う一般的な届出（要確認）

| 届出 | 提出先 | タイミング |
|---|---|---|
| 個人事業の開業届 | 税務署 | 事業開始から1か月以内（個人事業の場合） |
| 青色申告承認申請 | 税務署 | 期限が厳格。**税理士に確認** |
| 法人設立の各種届出 | 税務署・都道府県・市区町村 | 法人を作る場合 |
| 社会保険の適用 | 年金事務所 | 法人は原則強制適用 |
| 労働保険・雇用保険 | 労基署・ハローワーク | **従業員を雇う場合のみ**（妻1人なら不要の可能性） |

→ 法人格が未決（未決#6）なので、ここは法人格の決定後に税理士と確定させる。

## 加入を検討すべき保険

| 保険 | 目的 | 必要度 |
|---|---|---|
| 施設賠償責任保険 | 設備が原因で会員が怪我をした場合 | **必須扱い** |
| 傷害保険（指導中の事故） | 指導中の怪我 | **必須扱い** |
| 什器・設備の火災保険 | 設備の損害 | 推奨 |
| 休業補償 | 妻が働けなくなった場合 | **要検討（この事業では重要）** |

> **休業補償は真剣に検討する。** 妻1人が稼働の全てなので、妻が働けなくなると売上がゼロになる。
> `00_経営/事業概要.md` のリスク表「妻の稼働依存」への最も直接的な対策。

## 会員との契約で用意する書類

| 書類 | 内容 | 要チェック |
|---|---|---|
| 会員規約 | プラン・課金日・繰越・キャンセル・休会・退会・最低継続期間 | **専門家チェック必須** |
| 同意書・問診票 | 既往症・服薬・運動制限の申告、リスクの説明 | **専門家チェック必須** |
| 返金規定 | 中途解約時の取扱い | **専門家チェック必須**（前受金・特定商取引法の論点） |
| 個人情報の取扱い | 体組成・写真の利用範囲、SNS掲載の可否 | 必須 |

> **月額サブスクかつ最低継続期間ありの契約は、消費者保護の論点が出やすい。**
> 規約を自分で書いて終わりにせず、必ず専門家に見せる。ここを省くとトラブル時に戦えない。

## 次にやること

- [ ] シャワーを設けるか決める（→ 保健所確認の要否が決まる）
- [ ] 飲食物・サプリを扱うか決める
- [ ] 物件候補が決まったら、着工前に消防署へ相談
- [ ] 法人格の決定後、税理士と届出一覧を確定
- [ ] 会員規約・同意書・返金規定の専門家チェックを依頼（D−3までに）
