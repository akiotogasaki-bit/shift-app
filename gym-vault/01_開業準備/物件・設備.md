# 物件・設備

## 物件の条件（先に決めてから探す）

条件を決めずに内見を始めると、物件に計画を合わせてしまう。**条件が先。**

| 項目 | 条件（仮） | 確定 |
|---|---|---|
| エリア | 未定 | 未決#2 |
| 最寄駅からの徒歩 | **7分以内** | 要決定 |
| 広さ | 12〜18坪（個室1室＋受付・更衣） | 要決定 |
| 家賃上限 | **月200,000円（共益費込み）** | 要決定 |
| 階数 | 1〜2階が望ましい（地下・3階以上は体験申込が落ちる） | 要決定 |
| 居抜き／スケルトン | 居抜き（元ジム・元サロン）を優先 | — |
| 搬入経路 | マシンが入る（エレベーター・階段幅） | **内見時に必ず確認** |
| 電気容量 | 空調＋マシンで足りるか | 内見時に確認 |
| 水回り | シャワーを設けるなら給排水の可否 | 内見時に確認 |
| 防音 | 上下階への振動・音（ウェイトを落とす音） | **内見時に必ず確認** |
| 看板の掲出可否 | ファサードに出せるか | 内見時に確認 |

> **居抜き物件を優先する理由：** 内装工事が初期投資の最大項目（仮250万円）。元ジム・元サロンなら鏡・床・個室の一部が流用でき、数十万〜百万円単位で圧縮できる。

> **防音は後から直せない。** マンツーマンでもウェイトの落下音は出る。上階が住居の物件は要注意。

## 内見チェックリスト

内見は**5件以上。1件目で決めない。**

- ☐ 駅からの実測徒歩時間（自分で歩く。表示を信じない）
- ☐ 周辺の人通り（曜日・時間帯を変えて2回見る）
- ☐ 競合ジムの数と価格帯
- ☐ マシンの搬入経路（幅・高さ・曲がり角）
- ☐ 電気容量（分電盤を見る）
- ☐ 給排水の位置
- ☐ 天井高（ラックやバーベルを扱えるか）
- ☐ 上下階・隣の用途（住居か店舗か）
- ☐ 空調の有無と年式
- ☐ 看板の掲出条件
- ☐ 原状回復義務の範囲（**契約書で確認。スケルトン返しは退去費用が大きい**）
- ☐ 保証金の償却割合

### 設備投資の優先順位

```
1. 体組成計        — 成果の可視化 ＝ 退会防止 ＝ 売上の源泉
2. パワーラック＋バー＋プレート＋ベンチ  — これだけでマンツーマンは成立する
3. ダンベル
4. ケーブルマシン  — あれば種目が広がる
5. 有酸素マシン    — パーソナルでは後回しでよい
```

> **1と2だけで開業できる。** 初期投資を抑えて運転資金に回すなら、3〜5は開業後の利益から買い足す。
> 「設備が揃っていないと集客できない」は、完全個室マンツーマンでは当てはまりにくい。会員は設備ではなく**トレーナーと個室環境**で選んでいる。
