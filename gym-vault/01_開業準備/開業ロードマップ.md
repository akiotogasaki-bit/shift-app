# 開業ロードマップ（開業日からの逆算）

> **開業日が未決（未決#1）のため、現在は「開業日＝D日」として相対月で記載。**
> 開業日が決まったら、D−12 などを実年月に置き換える。

想定：2027年中の開業。本日 2026-10-04 時点で、2027年4月開業なら残り約6か月、10月開業なら約12か月。
**残り6か月を切っている場合、下の D−12〜D−9 を圧縮する必要がある → 最優先で開業日を決める。**

## クリティカルパス（遅れると開業日がずれるもの）

```
開業日の決定 → 妻の稼働確定 → 料金確定 → 資金計画 → 融資 → 物件契約 → 内装工事（2〜3か月）→ 開業
                                                              └→ 屋号決定 → 看板発注（1か月）
```

**内装工事と看板発注が最長リードタイム。** 物件契約が遅れると、そのまま開業日が後ろにずれる。
システム開発はクリティカルパス上にない（社長が並行で進められる）ので、焦って先に作らない。
