========================================
パーソナルジム_Vault 導入手順
========================================
作成日：2026-10-04

■ 1. 配置する

添付の パーソナルジム_Vault.zip を解凍し、フォルダごと下記に置く。

  /Users/togasakiakio/Downloads/パーソナルジム_Vault

※ お江戸弁当_Vault と同じ階層に並べる形。中に入れないこと（分離のため）。

■ 2. Obsidian で開く

Obsidian 起動 → 左下の Vault 切り替えアイコン
  → 「Open folder as vault」
  → 上の パーソナルジム_Vault を選ぶ

これでお江戸弁当とジムを、Obsidian 上でワンクリックで切り替えられる。

■ 3. 中身の構成

  CLAUDE.md                        ← 正本。社長の人格・判断基準・ルール
  00_経営/事業概要.md              ← 現在地。毎回ここを見る
  00_経営/意思決定ログ.md          ← 決定と未決11件
  00_経営/KPI.md                   ← 見る数字の定義
  01_開業準備/開業ロードマップ.md  ← 開業日からの逆算（D-12〜D+3）
  01_開業準備/タスク一覧.md        ← 今週やること
  01_開業準備/許認可・届出.md      ← すべて要確認扱い
  01_開業準備/物件・設備.md        ← 物件条件・内見チェックリスト
  02_料金と収支/料金プラン.md      ← 3案比較（B案推奨）
  02_料金と収支/収支シミュレーション.md ← 供給上限と損益分岐
  03_集客ブランディング/コンセプト.md   ← 妻が記入するノート
  03_集客ブランディング/集客チャネル.md
  04_システム開発/システム全体像.md
  04_システム開発/要件定義_予約顧客管理.md
  04_システム開発/データモデル.md  ← スプレッドシート構成の正本
  05_運営マニュアル/README.md      ← 開業後に埋める
  99_アーカイブ/README.md          ← セッション引き継ぎメモ置き場

■ 4. 次回ジムの相談をするときの始め方

新しいチャットで、こう言えば社長が起動する。

  「パーソナルジム_Vault を接続。CLAUDE.md を読んでから始めて」

CLAUDE.md の第0章に「セッション開始時の儀式」が書いてあるので、
CLAUDE.md → 事業概要.md → 意思決定ログ.md の順に読んでから作業に入る。

■ 5. 今いちばん埋めてほしい項目（CLAUDE.md 第8章）

 □ 開業予定日（年月）
 □ 出店エリア（最寄駅・徒歩分数）
 □ 想定物件の広さ・家賃レンジ
 □ 妻が週に稼働できる日数と時間帯  ← 売上の天井が決まる最重要項目
 □ 開業に充てられる自己資金の上限
 □ 融資を使うか
 □ 個室の数（1室か2室か）
 □ 法人格（お江戸弁当と同一法人 / 別会社 / 妻の個人事業）

このうち「妻の稼働日数・時間帯」が決まると、収支シミュレーションの
全数字が確定する。最優先。
