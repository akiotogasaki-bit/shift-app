# 運営マニュアル（開業後に埋める）

開業前は空でよい。**実際に回してから書く。** 想像で書いたマニュアルは使われない。

開業後に作る想定のもの

- [ ] 1日の流れ（開店準備 → セッション → 記録入力 → 閉店）
- [ ] 体験セッションの進め方（問診 → 測定 → 体験 → 案内 → クロージング）
- [ ] 入会手続きの手順（規約説明 → 同意書 → 会員登録 → プラン設定 → 初回課金）
- [ ] 月初の処理（残高の繰越確認 → 請求の生成 → 未収の確認）
- [ ] 月末の処理（稼働率の集計 → 退会者の記録 → KPI更新）
- [ ] キャンセル・無断欠席の対応手順
- [ ] 休会・退会の受付手順
- [ ] 設備の点検とメンテ周期
- [ ] 緊急時対応（会員の体調不良・怪我）← **これだけは開業前に作る**

> **緊急時対応だけは開業前に用意する。** 怪我や急な体調不良は開業初日に起こり得る。
> 連絡先（救急・会員の緊急連絡先）、やること、記録の残し方を1枚にしておく。
